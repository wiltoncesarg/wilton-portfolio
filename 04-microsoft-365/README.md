# Case 04 — Microsoft 365

## Overview

Hands-on administration and troubleshooting of selected Microsoft 365 services, with emphasis on Exchange Online, Microsoft Defender for email protection, licensing and mailbox migration.

## Exchange Online

Message Trace is the first investigation point for mail-flow problems, including delivery, rejection, filtering and mailbox-related issues.

## Microsoft Defender

When investigation indicates that a message, sender or domain should be allowed or blocked, the investigation continues in Microsoft Defender.

Activities include adjusting parameters, creating/editing rules, adding domains and supporting controlled phishing campaigns by allowing required domains.

## Licensing

Activities include checking whether a user has a license, verifying whether it provides the required service and assigning licenses when necessary.

## Mailbox Migration

A previous migration involved an external vendor. After the vendor did not complete the migration, the remaining mailbox migration activities were finalized internally.

The process used a native Microsoft 365 synchronization tool and involved:

1. Preparing the user set and credentials
2. Configuring the connector
3. Starting synchronization jobs
4. Monitoring the migration

## Identity Scope

The corporate environment uses on-premises Active Directory integrated with Microsoft 365.

**Administration of the on-premises Active Directory and identity synchronization is outside the scope of this role.**

## Result / Impact

Operational support for Microsoft 365 mail services, email security controls, licensing and mailbox migration activities.

## Technologies

Microsoft 365 · Exchange Online · Message Trace · Microsoft Defender · Email security · Licensing · Mailbox migration
